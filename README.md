Study Buddy Web App

Overview:
The Study Buddy Web App is a front-end prototype designed to help students quickly find study partners, 
communicate with them, and organize study sessions.
The main goal of this project is to reduce the difficulty students face when trying to coordinate study
time with others by providing a simple and interactive interface for matching, messaging, and scheduling.

Core Features:
-Find a Studdy Buddy
  - Users can browse or select a course
  - Matches are generated based on shared classes/interests
  - Displays available study partners
-Messaging System
  - Users can send messages to a selected study buddy
  - Messages appear dynamically on the screen using JavaScript
  - Temporary messages are used to simulate real interaction (no backend)
-Create Study Sessions
  -Users can create a study session
  -Invite a study buddy to join
  -Displays confirmation/feedback when a session is created
-Interactive UI Behavior
  -Buttons trigger actions (match, message, invite)
  -Messages and alerts update dynamically without reloading the page
  -Some UI feedback disappears after interaction (to avoid clutter)

Design Approach:
This project follows a user-centered design process, focusing on making tasks quick and easy to complete.

Key Design Decisions:
-Provide visible actions
-Reduce steps for core tasks
-Provide clear feedback per action
-Keeping a simple layout

Languages used:
-HTML
-CSS
-JavaScipt

**How to run program:**
1. Open the project folder
2. Locate the file named "home.html"
3. Double-click "home.html"
4. The web app will open in your default web browser
5. Use the interface to find a study buddy, send messages, and create sessions
